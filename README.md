## 💬 Prompt 工程案例

### 企业 AI 问答平台 Prompt 优化案例
AI平台网站：http://ai.tjlaiot.xinnuojinzhi.com/login?redirect=/

**场景：** 用户询问超出知识库范围的问题时，LLM 频繁回复"我不知道"

**V1 问题：** 拒绝率 42%，用户挫败感强

**V2 优化：**
你是一个专业的企业知识助手。当遇到不确定的问题时：

先说明"关于这个问题，我目前掌握的信息有限"
然后提供最相关的已知信息
最后引导用户提供更多上下文以便更好帮助他 禁止直接说"我不知道"或"我不清楚"。


**效果：** 硬性拒绝率从 42% 降至 8%，用户满意度提升
