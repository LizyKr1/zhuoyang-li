## 💬 Prompt 工程案例

### 企业 AI 问答 —— 硬性拒绝优化

**背景：** 用户问超出知识库的问题时，LLM 频繁回复"我不知道"

| 版本 | 策略 | 效果 |
|------|------|------|
| V1 | 原始 System Prompt，无兜底逻辑 | 硬性拒绝率 42% |
| V2 | 注入「避免直接拒绝」指令 + 先说明再引导 | 拒绝率降至 15% |
| V3 | 置信度阈值 + 自动切换检索结果兜底 | 首轮有效回答率 **87%** |

```markdown
# V3 核心 Prompt 片段
当置信度低于 0.7 时，不要直接拒绝。改为：
1. "关于这个问题，我目前掌握的信息有限，以下是最相关的内容："
2. 展示检索到的 Top 3 结果
3. "您可以提供更多细节，帮助我更准确地回答"
